## 1. Quality Assurance Philosophy & Governance

The core principle governing Aether v1.1.0 testing is **Non-Regression Primacy**:
> **Rule of Non-Regression:** The existing baseline of 260 passing unit and integration tests represents verified v1.0.0 functionality. Under no circumstances may any existing test be removed, disabled, or weakened to accommodate v1.1.0 feature changes.

All new tests introduced for v1.1.0 will expand upon this baseline, targeting a minimum coverage goal of **340+ passing tests** before v1.1.0 freeze.

## 3. Dedicated Test Suites for v1.1.0 Additions

### 3.1 Suite 1: Multimodal Vision-Language Testing (`MultimodalInferenceTests`)
1. **`testDualArtifactMetadataValidation()`**:
   - Asserts that all models marked `.visionLanguage` have non-nil companion `mmproj` metadata, valid filenames, and positive byte sizes.
2. **`testImagePreprocessingDownsamplesLargeImages()`**:
   - Feeds a synthetic $4000 \times 3000$ test image into `ImagePreprocessor`.
   - Confirms resulting dimensions do not exceed $1344 \times 1344$ and aspect ratio is preserved within $\pm 0.5\%$.
3. **`testImagePreprocessingRejectsUnsupportedFormats()`**:
   - Verifies corrupted or non-image payloads (e.g. `.exe`, text files) throw `ImageProcessingError.unsupportedFormat`.
4. **`testCLIPEmbeddingTokenAllocation()`**:
   - Validates that `clip_ctx` token evaluation correctly allocates image tokens without exceeding the allocated context budget.
5. **`testVisionLanguageInferenceE2E()`**:
   - Loads `Qwen2-VL-2B-Instruct-Q4_K_M.gguf` + `mmproj` on an Apple Silicon test node.
   - Submits a known test pattern image and validates semantic text completion.

### 3.2 Suite 2: Specialized Engines Testing (`SpecializedEngineTests`)
1. **`testAudioEngineLifecycleAndUnload()`**:
   - Initializes `WhisperAudioWorker`, simulates a 2-second audio buffer transcription, and confirms full memory deallocation upon `unload()`.
2. **`testEngineArbitrationUnderMemoryConstraint()`**:
   - On a simulated 8GB RAM profile, requests `StableDiffusionWorker` while `LlamaMultimodalWorker` is active.
   - Verifies the coordinator automatically unloads the LLM before loading Diffusion weights.
3. **`testSpecializedModelsBlockedFromStandardWorker()`**:
   - Verifies that attempting to load a Whisper or Stable Diffusion model into `LlamaInferenceWorker` throws `InferenceError.specializedEngineRequired`.

### 3.3 Suite 3: Resilient Download Manager Testing (`DownloadManagerV2Tests`)
1. **`testHTTPRangeHeaderGenerationFromExistingPartialFile()`**:
   - Creates a 5 MB mock file at destination URL.
   - Initiates download and confirms outgoing request contains `Range: bytes=5242880-`.
2. **`testStreamingSHA256ChecksumCalculation()`**:
   - Feeds multi-part byte chunks through `CryptoKit.SHA256` streaming delegate.
   - Compares resulting hash against static `shasum -a 256` output.
3. **`testDiskSpacePreflightRejectsInsufficientStorage()`**:
   - Mocks available volume capacity at 5 GB.
   - Attempts to start download of a 10 GB model; asserts `DownloadError.insufficientDiskSpace` is thrown before any network socket opens.
4. **`testDownloadSessionPersistenceAcrossRestarts()`**:
   - Simulates mid-stream cancellation, writes state to SQLite `download_queue`, re-initializes `ModelDownloadManager`, and confirms the task state is restored as `.paused`.
5. **`testAtomicInstallationPreventsCorruptedModelRegistration()`**:
   - Simulates a checksum mismatch at byte EOF.
   - Verifies the `.download` file is discarded and never moved to the final `.gguf` location.

### 3.4 Suite 4: Memory Pressure & Hardware Governor Testing (`MemoryGovernorTests`)
1. **`testKVCacheFormulaCalculationAcrossArchitectures()`**:
   - Validates KV cache math against known reference values for Llama-3 (8B), Qwen-2.5 (14B), and Phi-4 (14B).
2. **`testMemoryPressureWarningTriggersCachePruning()`**:
   - Simulates a Darwin `DISPATCH_SOURCE_TYPE_MEMORYPRESSURE` warning.
   - Asserts that inactive conversation message view models and cached markdown AST trees are evicted.
3. **`testMemoryPressureCriticalTriggersModelUnload()`**:
   - Simulates a `.critical` memory pressure event.
   - Verifies idle background inference workers release their Metal unified memory buffers.

### 3.5 Suite 5: SQLite Database Migration Testing (`DatabaseMigrationV6Tests`)
1. **`testMigrationV5ToV6PreservesExistingConversations()`**:
   - Populates a v5 SQLite database with test conversations, messages, and FTS5 indices.
   - Runs v6 migration (adding `download_queue` and `multimodal_attachments` tables).
   - Verifies 100% data preservation and foreign-key integrity.
2. **`testMultimodalAttachmentCascadeDeletion()`**:
   - Inserts image attachments linked to a test message.
   - Deletes parent conversation; verifies attached image references in SQLite are cascaded cleanly.

## 4. Release Packaging & Clean-Machine Simulation Suite

Prior to any v1.1.0 release candidate sign-off, the following automated release pipeline verification tests must pass:

```bash
# 1. Full compilation and test execution
xcodebuild test -scheme Aether -configuration Debug -destination "platform=macOS,arch=arm64"

# 2. Package release DMG
./scripts/package_release.sh

# 3. Notarization validation
xcrun stapler validate dist/Aether-v1.1.0-arm64.dmg

# 4. Strict Gatekeeper assessment
spctl --assess --type execute -v build/DerivedData/Build/Products/Release/Aether.app
spctl --assess --type open --context context:primary-signature -v dist/Aether-v1.1.0-arm64.dmg
```

### Clean-Machine Virtual Sandbox Test
- Execute automated launch script in an isolated APFS sparse disk image.
- Confirm first-launch database initialization completes without errors.
- Confirm standard security prompts (`sandboxed_file_reader` permission dialog) display correctly.
