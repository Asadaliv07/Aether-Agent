## 5. Curated Catalog & Hardware Compatibility Baseline

### 5.1 Verified Curated Catalog
- **Total Curated Models:** 56 models across 18 architectural families (Llama, Qwen, Mistral, Gemma, Phi, DeepSeek, GLM, Granite, Command R, Falcon, InternLM, Yi, OLMo, SmolLM, OpenELM, StarCoder, BGE, Nomic).
- **Endpoint Verification:** All 56 repositories map to active, verified production Hugging Face repositories returning HTTP 200.

### 5.2 DeepSeek V3 671B Clarity & Remediation
- **Storage Requirement:** 404.43 GB across 9 shards (`DeepSeek-V3-Q4_K_M-00001-of-00009.gguf` through `00009-of-00009.gguf`).
- **RAM Requirement:** Requires **420+ GB unified memory** (including KV cache and compute buffers).
- **Single-Mac Feasibility:** Maximum unified memory on Apple Silicon is 192 GB (M2/M3/M4 Ultra). A single Mac cannot load or execute this model.
- **Catalog Status:** Marked `.incompatible("Requires 404.43GB disk storage & 420GB+ unified memory across 9 shards. Exceeds single Mac hardware limit (192GB max).")`.
- **UI Guardrail:** In `ModelHubCardView` and `ModelDetailSheet`, the download button is disabled and replaced with an explicit non-interactive `Incompatible` badge.

### 5.3 Specialized Inference Engines
- Audio models (`Whisper Large v3 Turbo`, `Whisper Base`, `Breeze-TTS 2`) and diffusion models (`FLUX.1 Schnell`, `Stable Diffusion v1.5`) are marked `.requiresSpecializedEngine`.
- Direct LLM execution is disabled; specialized engine runtimes are roadmapped for v1.1.0.

## 7. Known Limitations of v1.0.0

1. **Multimodal Perception (Vision):** The four vision models (Qwen2-VL 7B/2B, Pixtral 12B, MiniCPM-V 2.6) load primary weights for text generation only. Processing image inputs requires a companion `mmproj` tensor file and `llava_context` bridge, roadmapped for v1.1.0.
2. **Audio & Image Generation:** Whisper, Stable Diffusion, and Breeze-TTS are non-executable in the embedded text engine and are marked as requiring specialized engines.
3. **Single-File Downloader:** `ModelDownloadManager` does not orchestrate multi-shard model downloads (e.g. DeepSeek V3 9 shards).
4. **Ad-Hoc Distribution:** Unnotarized binary requires a manual Gatekeeper security override on first launch.
